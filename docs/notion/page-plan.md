## A. はじめに

### A-1. BPIとは？ （icon: 📈）
- 導入: BPIM2 が何を計算するツールかを1段落で。
- `## BPIとは` — NORI氏の定義へのリンク（`https://norimiso.net/bpi`）。100=皆伝平均・上限なし・0が全one basis の概略。
- `## BPIM2での3つのBPI`
  - 単曲BPI: 1曲のEXスコアから算出
  - 総合BPI（☆12 / ☆11）: 全対象曲の単曲BPIのべき乗平均。ダッシュボード等に表示
  - 皆伝内推定順位: 総合BPIから推定した皆伝内順位（ダッシュボード・更新ログに表示）
- `## 譜面係数（coef）` — BPIM2独自の係数。解説記事へリンク（`https://bpimanager.github.io/BPIM2_Coef_explanation/`）。
- `## 定義変更について` — 親ページの「BPI定義算出の変更点について」ページへ内部リンク。
- 🖼 なし（またはダッシュボードの現在BPIウィジェット1枚）。テキスト主体。

### A-2. アカウントを登録する （icon: 🆔）
- 導入: ログイン方法とプロフィールの初期設定。
- `## ログイン` — 右上「ログイン」。認証プロバイダ（Google など Firebase Auth）。複数アカウント切替（アカウント切り替え/新規アカウントを追加）に触れる。
- `## プロフィールの初期設定` — 設定 → プロフィール設定モーダル:
  - **表示名**（必須・重複チェックあり。連携サービスの本名は使われない旨）
  - **IIDX ID**（半角数字8桁）
  - **アイコン**（連携サービス/ランダム/アップロード）
  - **X ユーザー名**・**自己紹介**（任意）
- `## プロフィールを公開` — 既定で公開推奨。非公開の詳細は「フォロー」ページへリンク。
- `## 詳細情報の公開設定` — アリーナクラス / 所属エリア / 段位(SP/DP) の個別公開トグル。毎日午前1時頃自動更新。
- 🖼 プロフィール設定モーダル（自分の情報＝ぼかし不要）

### A-3. データを登録する（初回インポート） （icon: 📥）
- 導入: 初めてスコアを取り込む手順。以降の定期更新は「スコアを更新する」ページへ。
- `## 1. CSVを用意する`
  - アーケード: IIDX公式サイト(e-amusement)からCSVダウンロード
  - INFINITAS: 打鍵カウンタ / リザルト手帳等から出力したCSV/TSV（Reflux は表記揺れ注意）
- `## 2. インポート画面に貼り付ける` — サイドバー「インポート」→ **スコアインポート**タブ。
  - CSVを**改変せず全文**貼り付け（またはクリップボードから直接読み取り）
  - **保存先バージョン**を選択（INFINITASデータは "INFINITAS" に変更）
  - **インポートを開始**
  - 完了モーダル: 更新件数・総合BPI(☆12)の変化・「今回の更新ログを確認」「全スコア一覧を表示」
- `## 3. かんたんに取り込む方法`
  - **Android用アプリ**（コピペ不要、公式サイトから自動同期。APK直接インストール＝提供元不明アプリ扱い、要自己責任）
  - **ブックマークレット**（e-amusement GATE上で実行。デスクトップ=ブックマークバーにD&D、モバイル=コードをブックマークに貼付。実行後インポート画面で「インポートを開始」）
- `## IIDXタワーインポート` — **IIDXタワーインポート**タブ。タワーCSVを貼り付け→取り込み（鍵盤/スクラッチのノーツ数）。ダッシュボードのIIDXタワーウィジェットに反映。
- 🖼 インポート画面（スコアインポートタブ）、🖼 インポート完了モーダル（自分のデータ）、🖼 かんたん取り込み（Android/ブックマークレットのアコーディオン）

## B. 各ページの使い方

### B-1. スコア一覧（プレイ済み / 未プレイ） （icon: 🎼）
ルート: `/my/{version}`（プレイ済み） / `/my/unplayed/{version}`（未プレイ） / `/my/all/{version}`（全曲は別ページ「ベータ版機能」へ）
- 導入: 自分のスコアを一覧・絞り込み・並び替えする画面。
- `## プレイ済み一覧` — サイドバー「スコア一覧 > プレイ済み」。
  - `### フィルターバー` — VERSION / LEVEL(☆11・☆12) / DIFFICULTY(HYPER・ANOTHER・LEGGENDARIA)。操作テーブル。
  - `### テーブルの列` — 楽曲名・EXスコア・スコアレート・DJランク・BPI・前作比較 等（実列は要現物確認）。列ヘッダで並び替え。
  - `### 楽曲をクリック` — 楽曲詳細モーダル（履歴 / ランキング / ライバル / 定義 タブ）。
- `## 未プレイ一覧` — サイドバー「スコア一覧 > 未プレイ」。まだスコアが無い対象曲。埋めるべき曲の把握、そのままインポートで反映。
- `## URLで条件を共有` — フィルタ条件はクエリに入るのでURL共有で同じ絞り込みを再現可能。
- 🖼 プレイ済み一覧（フィルタ+テーブル、自分のスコア）、🖼 楽曲詳細モーダル、🖼 未プレイ一覧 🔒（ランキング/ライバルタブを写す場合は他者名ぼかし）

### B-2. スコアを更新する（更新の記録と管理） （icon: 🔁）
ルート: `/import` / `/users/{userId}/logs/{version}` ほか summary 系
- 導入: 2回目以降のインポートで「差分」がログとして記録される仕組みと、その確認・削除。
- `## スコアログを追加する`
  - インポートを再実行すると、前回との差分のみが1つの「更新（バッチ）」として記録される
  - 完了モーダルから「今回の更新ログを確認」でそのバッチへ直行
- `## 更新履歴を確認する` — サイドバー「スコア更新ログ」（`/users/{userId}/logs/{version}`）。
  - `### 一覧` — バッチ単位のカード（更新件数・BPI上昇幅計・総合BPI・推定順位）。「詳細を見る」。
  - `### 表示の切替` — バージョン / **プレイ日単位 ↔ インポート日単位** / 表示粒度（日・週・月・作品）。操作テーブル。
  - `### バッチ詳細` — サマリー / 更新楽曲タブ、BPI分布・ランク分布、BPI伸び幅ランキング・BPIランキング・**ライバルに勝利**（当時ライバルを上回ったもの）、共有ボタン。
  - `### まとめページ` — 日/週/月/作品ごとの「プレイ記録まとめ」（`/users/{userId}/logs/{version}/summary/...`、`/monthly-review/{month}`）。
  - `### バージョン比較` — 現バージョンと前作のスコア比較。
- `## 更新履歴を削除する` — バッチ詳細の「この更新を削除」。確認ダイアログ（取り消し不可、紐づくスコアログが完全削除）。
- 🖼 更新ログ一覧（自分）、🖼 バッチ詳細（サマリー）、🖼 「ライバルに勝利」セクション 🔒（相手名ぼかし）、🖼 削除確認ダイアログ

### B-3. ソーシャル（タイムライン・通知・フォロー管理） （icon: 🗣️）
ルート: `/timeline` / `/ranking/global` / `/users/{userId}/following` / `/users/{userId}/followers` / 通知ベル
- 導入: フォローした相手の活動を追い、交流する機能群。フォローの手順自体は「プレイヤーをフォロー…」ページへリンク。
- `## タイムライン` — サイドバー「ライバル > タイムライン」。フォロー中ユーザーのスコア更新ログが時系列で流れる。
  - `### 表示モード` — すべて / 自分がプレイ済み / **逆転された曲**。操作テーブル。
  - `### 絞り込み` — プレイヤー名・楽曲名で検索。
- `## 通知` — 右上の通知ベル。
  - 追い抜き通知（ライバルに自分のスコアを抜かれた）
  - フォローリクエスト（非公開時）／承認結果／既存フォロワーの承認待ち（「承認待ち」タブ）
- `## フォロー中／フォロワー一覧` — プロフィールの「フォロー」「フォロワー」。
  - `### リスト管理` — フォロー中ユーザーを自分用リストに分類（他人には共有されない）。編集モード・リスト管理モーダル。
- `## 全体ランキング` — サイドバー「ライバル > 全体ランキング」。総合BPI・個別楽曲・IIDXタワーのランキング（BPIM2内実順位ベース）。行のユーザーからプロフィールへ。
- 🖼 タイムライン 🔒、🖼 通知ベル（ドロップダウン）🔒、🖼 リスト管理モーダル 🔒、🖼 全体ランキング 🔒

### B-4. 比較（ライバル比較・対戦） （icon: ⚔️）
ルート: `/analytics`（比較） / `/rivals`（ライバル一覧） / `/rivals/{userId}`（1対1） / `/rivals/search`（探す）
- 導入: 自分のスコアを他者・過去の自分・目標値と突き合わせる機能。
- `## 比較（/analytics）` — サイドバー「分析 > 比較」。
  - `### 比較対象を選ぶ` — 「比較対象を設定」から選択。種類テーブル:
    | 種類 | 内容 |
    | 個別ライバル | フォロー中の1人と比較 |
    | ライバル平均 / ライバルTOP | フォロー中全員の平均 / 最高 |
    | アリーナ平均 | 指定アリーナランク帯の平均（BPIM申告ベース、実値と乖離あり） |
    | 過去バージョン(自分) / 自己歴代 / 自己歴代(今作除く) | 自分の過去スコア |
    | AAA達成 / MAX-達成 / WR | 各曲の到達必要スコア |
  - `### 比較テーブルの見方` — 自分 vs 対象、BPI差、レベル/難易度フィルタ、ページング。
- `## ライバル一覧（/rivals）` — フォロー中ユーザーごとの勝敗（勝ち越し/負け越し曲数）。リストフィルタ、編集。ユーザーをクリックで1対1へ。
- `## 1対1のスコア比較（/rivals/{userId}）` — 楽曲一覧 / 分析タブ。勝ち(BPI上回り)・負け・平均BPI差、上回っている/負けている上位曲、BPI vs BPI 散布図。並び替え（勝ち越し多い順 等）。
- `## ライバルを探す（/rivals/search）` — 「プレイヤーをフォロー…」ページの1章と重複するため要点＋リンク。総合BPI/レーダー要素で実力の近いユーザーを提案、シャッフル、ユーザー名・IIDX IDで検索。
- 🖼 比較の対象選択モーダル、🖼 比較テーブル 🔒、🖼 ライバル一覧 🔒、🖼 1対1スコア比較（分析タブ）🔒

### B-5. 指標（AAA達成難易度表・アリーナランク平均） （icon: 📐）
ルート: `/metrics` / `/metrics/AAADifficultyTable` / `/metrics/arenaAverage/{version}`
- 導入: IIDX全体の傾向データ。自分のスコアを重ねて到達度を確認できる。
- `## AAA達成難易度表` — サイドバー「分析 > AAA達成難易度表」。
  - BPIに基づく AAA / MAX- 達成に必要な実力で楽曲をグループ化。
  - フィルタ: バージョン / レベル / 目標(AAA・MAX-・カスタム) / 並び替え基準(目標・マイスコア) / 達成状況 / 目標まであとN点以内 / カード表示。
  - ログイン時は自分のスコアで達成状況が色分け。
- `## アリーナランク平均` — サイドバー「分析 > アリーナランク平均」。
  - BPIM登録ユーザーのアリーナランク申告ベースの平均（実値と乖離あり／移行期間はBPIMデータ）。
  - 一覧タブ（楽曲別の平均スコア/スコアレート/EXスコア、ランク選択、楽曲名検索）／分析タブ（レーダー項目別 総合BPI比較、BPI上位15/下位10、BPI分布、自分との比較）。
- 🖼 AAA達成難易度表（フィルタ+表、自分のスコア反映）、🖼 アリーナランク平均（一覧）、🖼 アリーナランク平均（分析タブ）

### B-6. 設定 （icon: ⚙️）
ルート: `/settings`
- 導入: アカウント・表示・データ管理。上から順に:
- `## プロフィール設定` — 表示名 / IIDX ID / アイコン / X / 自己紹介 / プロフィール公開 / 詳細情報の公開設定。（→ A-2 と重複するので要点＋リンク）非公開時は**フォロー招待URL**欄（→ フォローページ）。
- `## 言語設定` — 日本語 / 英語 / 繁体字中国語 / 韓国語。
- `## データ移行（BPIManager → BPIM2）` — 旧BPIMのスコアを引き継ぐ。**現在のBPIM2データを全削除して置換**、取り消し不可、2〜3分。（親の「アカウントデータの移行」ページへもリンク）
- `## APIキー` — API経由でのデータ取得・更新用。発行/再発行（旧キー即時無効）。表示は一度きり。
- `## MCP接続（OAuth）` — DCR非対応のMCPクライアント向けに Client ID/Secret を手動発行。MCPエンドポイントURL。（→ ベータ「アシスタント」/ MCP へリンク）
- `## ダッシュボードレイアウト` — ウィジェットの表示/並び/カラム数。**この端末のみ**に保存。
- `## テーマ・フォント設定` — ダーク / ライト / ゲーミング、フォント。ブラウザ保存。
- `## データエクスポート` — スコアをCSVでDL（複数バージョンはZIP）。出力フィールド選択。
- `## アカウント削除` — BPIM2/BPIM を完全削除。取り消し不可、ユーザー名入力で確認。
- 🖼 設定ページ全体（またはセクションごと）、🖼 プロフィール設定モーダル、🖼 レイアウト編集、🖼 テーマ設定。すべて自分のデータ＝ぼかし不要。

### B-7. ベータ版機能 （icon: 🧪）
ルート: `/optimizer` / `/songs`・`/songs/{songId}` / `/my/all/{version}`（+ `/tickets` を軽く）
- 導入: サイドバー「ベータ版機能」。仕様が変わりやすい旨の注意書き。
- `## アシスタント（総合BPIを伸ばす）` — `/optimizer`。
  - 「どの曲をあと何点伸ばせば効率よく目標総合BPIに届くか」を逆算し強化メニューを生成。
  - 条件設定: 目標総合BPI / 改善曲数の目安 / アルゴリズムの性格（スパルタ↔フレキシブル）/ 現在の総合BPIを考慮 / 重視するプレイスタイル（未プレイを埋める↔既プレイを伸ばす）/ レーダー要素で対象楽曲を指定。
  - 結果: 推奨ルート（効率順）カード、青ゲージ＝総合BPIへの貢献度、「結果を保存」→ 保存済みプラン一覧。
  - おすすめ設定: 目標=現在+1.0 / 30曲 / フレキシブル。
- `## 楽曲情報` — `/songs`。楽曲メタ情報・難易度属性（皿・ソフラン・CN・物量など）の一覧と検索、当たり譜面検索、攻略コメント（誰でも書き込み可）。楽曲詳細ページのタブ（Wiki / 類似 / パターン / …）。
- `## 全曲データ（☆10以下含む）` — `/my/all/{version}`。通常のスコア一覧は☆11・☆12対象だが、ここでは☆10以下も含む全難易度を表示。
- `## （参考）ランダムレーンチケット当たり探索` — `/tickets`。所有チケットのパターンから使うべき楽曲をレコメンド。1〜2文で紹介。
- `## MCPサーバー連携` — LLM（ChatGPT/Claude等）から自分・ライバルのスコアを分析させる。エンドポイント `https://bpi2.poyashi.me/api/mcp`。接続は設定「MCP接続(OAuth)」。
- 🖼 アシスタント（条件設定＋結果）、🖼 楽曲情報一覧、🖼 楽曲詳細ページ、🖼 全曲データ
