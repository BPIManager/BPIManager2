# 0008: gamma補正への信頼度重み付け（IQR基準）

- **ステータス**: 採用
- **記録日**: 2026-09-05
- **対応issue**: #308（gamma補正）

## 背景

決定記録0005・issue #308で導入したgamma補正は、「WRが全曲共通の典型的な位置(z100_typical)からどれだけズレているか」に対数比で連続的に反応する設計になっていた。実データで検証したところ、この式は真に外れている曲（issue #299実測: 対象1,300曲中45曲程度、IQR基準では650曲中36曲）だけでなく、**中央値から少しでもズレていれば大多数の「普通の曲」にも補正をかけてしまっていた**（実測: 650曲中325曲がgamma>1）。

具体例: 「AA」[ANOTHER]（☆12、弁別力sigma=0.69で全650曲中92パーセンタイル、いわゆる「地力譜面」）はIQR基準で外れ値ではない（z100=5.71、外れ値境界は[4.69, 8.41]）にもかかわらず、gamma=1.13の補正を受けて単曲BPIが現行より4.90点も厳しく出ていた。

曲別の平均バイアスとgammaの相関は-0.632（gammaが1を超える曲ほど系統的に厳しい）、z100との相関は+0.632（gammaの算出元そのものと完全に対応）であり、gamma補正自体が新たな系統的バイアスの発生源になっていることを確認した。

## 検討した選択肢

| 案 | 概要 | 結果 |
|---|---|---|
| A: IQR不感帯（外れ値以外はgamma=1固定） | 統計的外れ値(36/650曲)のみ補正、それ以外は無補正 | 設計は単純だが、外れ値境界の内外で補正が不連続にジャンプする欠点がある（採用見送り） |
| B: 観測数に基づく信頼度重み（SNR方式） | 曲ごとの観測数`n`からz100の推定誤差を求め、実際のズレ/推定誤差(SNR)の2乗を重みにする | **不採用**。観測数が多い曲（ALS対象母集団5,942人からの観測がほとんどの曲に及ぶ）ほど推定誤差が非常に小さくなり、僅かなズレでも「統計的に有意」と判定されてしまう。実測でAA[A]のgammaは全く変化しなかった（1.1328→1.1328） |
| C: IQRに基づく信頼度重み（採用） | z100分布のIQR（曲間の自然なばらつき）を物差しに、ズレの大きさ(d=ズレ/IQR)の2乗を重みにする | 連続的（不連続なし）で、かつ「観測数が多いほど何でも有意になる」というB案の欠陥を回避できる |

## 結論

C案（IQRベースの信頼度重み）を採用する。

```
d      = |z100_j − z100_typical| / IQR(z100)
weight = d² / (d² + 1)
gamma_j_final = 1 + weight * (gamma_j − 1)
```

`weight`の関数形（`d²/(d²+1)`）は、このセッションで繰り返し使ってきた「情報量 / (情報量 + 1単位の疑い)」という縮小推定の枠組み（決定記録0006・0007の`w = den/(den+residualVariance)`と同じ形）の応用であり、新たに導入した考え方ではない。

## 影響（実測）

- AA[A]のgamma: 1.133 → 1.050、単曲BPIの現行との差分: -4.90 → -2.11
- gamma分布: gamma≈1(0.98〜1.02)の曲数が119/650 → 392/650に増加
- gammaと曲別平均バイアスの相関: -0.632 → -0.214
- 単曲BPI差分（全体）: 平均-0.50 → -0.37、中央値-0.51 → -0.31、p10/p90の幅も縮小

`generate-new-bpi-params.ts`でz100分布のIQRを計算し`songParams.json`の`z100Iqr`として保存、`NewBpiCalculator.gammaFor`で参照する。
