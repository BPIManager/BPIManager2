# 0007: 単曲BPIのz0アンカーを皆伝平均ベースからアリーナA帯在籍者ベースに変更

- **ステータス**: 採用（[0005](0005-new-bpi-distribution-model.md)の「z0は各曲の皆伝平均のz位置の全曲中央値」という判断を上書き）
- **記録日**: 2026-09-05
- **対応issue**: #307（z0/z100アンカーの決め方）

## 背景

決定記録0005で、単曲BPIのBPI=0アンカー`z0`を「各曲の皆伝平均が示す潜在能力位置の全曲中央値」（実測`z0≈-0.132`）と定義していた。

`/new-bpi`での検証中、実データで単曲BPIの平均バイアスを調べたところ、新方式は現行方式より系統的に厳しく出ることが分かった（実測: 単曲BPI差分の平均-1.24、中央値-1.31）。この原因を検討する過程で、「BPI0=皆伝平均」という前提自体に疑問が呈された: **皆伝を取得していなくても☆12を上手くプレイできるプレイヤーは存在し、「皆伝合格者」という母集団に限定する必然性はない。**

## 検討した選択肢

| 案 | z0の定義 | 実測（単曲BPI差分） |
|---|---|---|
| A（決定記録0005、旧採用） | 各曲の皆伝平均が示す潜在能力位置の全曲中央値 | 平均-1.24、中央値-1.31 |
| B: 全曲共通定数を撤回しz0=0固定（母集団平均） | ALS推定母集団（アリーナ上位クロール+bpim2ユーザー、5,942人）全体の`a_i`平均（正規化により定義上0） | 平均-2.87、中央値-3.06（**悪化**） |
| C: アリーナA帯在籍者の`a_i`**平均** | 実測`z0≈-0.019` | 平均-2.64、中央値-2.80（**悪化**） |
| D: アリーナA帯在籍者の`a_i`**中央値** | 実測`z0≈-0.193`（本番の統合母集団で算出） | 平均-0.50、中央値-0.51（**大幅改善**） |

B・Cが悪化したのは、ALS推定母集団やアリーナA帯全体の`a_i`分布が、皆伝平均の位置（-0.132）より高い（＝厳しい）位置にあるため。特にC（A帯在籍者の平均）は、アリーナA帯在籍が総合的な立ち回り（勝率・プレイ量等）で決まり☆11/12最難関の実力だけでは決まらないことから、一部の突出したプレイヤーが平均を引き上げ、母集団の「典型的な実力」からずれた値になっていた（実測: 平均-0.019に対し中央値-0.219、分布が右に歪んでいる）。

D（A帯在籍者の中央値）は、この歪みの影響を受けにくく、現行方式との単曲BPI平均バイアスをほぼ解消した。

## 結論

D案（アリーナA帯在籍者の`a_i`の中央値）を採用する。

- 「皆伝合格」という関門を経由せず、実在する競技人口（アリーナA帯、a1〜a5）の典型的な実力を直接の基準にする
- 中央値を使う考え方自体は決定記録0005の旧z0算出（各曲の皆伝平均位置の中央値）と同じ設計思想（外れ値に頑健な統計量を使う）の延長であり、新たな手法を持ち込んだわけではない。対象母集団を「皆伝合格者」から「アリーナA帯在籍者」に変えただけ
- これは「現行方式の平均に合わせる」という循環した調整ではない。むしろ逆で、独立した実在の母集団（アリーナA帯）を基準に選び直した結果、たまたま現行方式に近い値になった。現行方式に意図的に合わせにいった値ではないため、今後の母集団・データ更新で再度乖離する可能性はある

## 影響

- `songParams.json`の`z0`が`-0.132`から`-0.193`に変わる（`scripts/generate-new-bpi-params.ts`で再生成）
- 単曲BPIの現行方式との平均バイアスが-1.24→-0.50に縮小
- `z100`・`zRef`・`gamma`補正の仕組み自体・`residualRmse`ベースの縮小推定（決定記録0006）には変更なし
