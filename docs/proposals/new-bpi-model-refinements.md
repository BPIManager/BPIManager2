# 新方式BPI: 検証の詰めとモデル拡張の検討

- **ステータス**: 検討中（issue #367 epic、サブ #368〜#371）
- **前提**: 決定記録 [0005](../decisions/0005-new-bpi-distribution-model.md)〜[0008](../decisions/0008-new-bpi-gamma-confidence-weighting.md)、数式は [`docs/bpi-math.md`](../bpi-math.md) §7、恣意性の棚卸しは [`docs/bpi-new-formula-deviation-audit.md`](../bpi-new-formula-deviation-audit.md)
- **関連**: `src/lib/bpi/newBpi.ts`（`NewBpiCalculator`）、`scripts/generate-new-bpi-params.ts`（ALS生成パイプライン）

## 背景 / 動機

新方式BPI（分布ベース2母数潜在能力モデル `t_ij = μ_j + σ_j·a_i + ε_ij`）の理論的検討・実データ検証を経たレビューで、**手法上の宿題3点**が挙がった。いずれも「新方式を本採用するか」の判断材料として、着手前に潰しておきたい。

前提として **WR = BPI100 はBPIの定義的公理**（放棄するなら BPI である必要がなくなる）であり、z100 を全曲共通定数にする案（元 #302 案A、決定記録 0005 §2）は選択肢として成立しない。gamma 補正はこの制約下での必然的なコストである。この整理と、gamma の IQR 信頼度重みを「ベイズ的導出」ではなく「関数形を借りた減衰関数」と正しく分類し直すドキュメント修正は #368 で扱う（本提案書はモデル側の3点を扱う）。

## 1. ALS適合度の holdout 検証（#369）

### 課題

`generate-new-bpi-params.ts` L437-438 の `R² = 0.86` / 残差RMSE は `allT`（フィット全体）で算出した **in-sample 値**。自由パラメータ `μ_j, σ_j`（約1,300曲 × 2）＋ `a_i`（約5,300人）を持つ双線形モデルの in-sample R² は、観測数の少ない曲・少曲プレイヤーで適合度を過大評価する。

### 検討する選択肢

| 案 | 概要 | 評価 |
|---|---|---|
| A: このまま（in-sample のみ） | 現状 | 過学習・経年劣化の有無を示せない。本採用の説得力に欠ける |
| B: セル holdout | `(i,j)` を 10〜20% マスク → 残りで ALS → マスク分を予測、OOS R²/RMSE | matrix-completion の標準。追加 ~30行 + ALS 2回目。**採用** |
| C: 時間 holdout | 03-21 クロールのみでフィット → 05-26 のスコアを凍結パラメータで予測 | パラメータの経年（再生成頻度の根拠）が測れる。両データは統合前の形で手元にある。**B と併用** |
| D: k-fold | セル 5-fold | より締まった推定。ALS が高速（~19反復）なので任意で追加 |

### 方針

**B + C。** さらに held-out セルを「曲の観測数 `n_j`」「プレイヤー保有曲数」でバケットし、少観測側の劣化を可視化する。OOS 値を `bpi-math.md` §7.2 と Notion「複合的な影響」に追記。乖離の大きい層があれば、それが 2.（残差分散）の縮小の強さの判断材料になる。

## 2. 残差分散の曲別化（#370）

### 課題

`newBpi.ts` は `NEW_BPI_RESIDUAL_RMSE` の単一スカラーを、縮小推定 `a = num/(den + residualVariance)` と未プレイ曲埋め `w = den/(den + residualVariance)` の両方に使う。残差分散は曲ごと（`bpi-math.md` §7.4 脚注が「弁別力の低い曲ほど `z_ij` のばらつきが大きい」と認識済み）・実力帯ごとに異なるはずで、単一値は「ノイズの大きい曲」と「安定して出る曲」を同列に扱う。

### 検討する選択肢

| 案 | 概要 | 評価 |
|---|---|---|
| A: 単一 σε²（現状） | — | 実装が最も単純。上記の不等分散を無視 |
| B: 曲ごと σε,j²（逆分散加重 / GLS） | 収束後に `σε,j²` を推定し、`a` 推定を精度単位の加重に置き換え | ALS の枠組みを壊さない。式もむしろ素直になる（下記）。**採用** |
| C: B + 実力帯依存 σε,ij² = σε,j²·g(a_i) | 強者ほど残差小（WR近傍で `z` が詰まる）をモデル化 | 重みが未知の `a_i` に依存 → 反復が要る。**まず測定し、有意な傾きがある時だけ** |

### B の式（精度単位に統一）

```
σε,j²_raw   = Σ_i (t_ij − μ_j − σ_j·a_i)² / n_j
σε,j²       = (n_j·raw + ν·global) / (n_j + ν)      // 少観測曲は global へ縮小、ν ≈ 20〜50
num*        = Σ_j σ_j(t_ij − μ_j) / σε,j²
den*        = Σ_j σ_j² / σε,j²                      // 有効情報量
a_shrunk    = num* / (den* + 1)                     // 事前分散 1 が明示的に出る
w (未プレイ) = den* / (den* + 1)
```

### 方針

**B。** ALS 反復自体の GLS 化ではなく、**収束後に1回の逆分散リ重み付けパス**（フル GLS-ALS は不安定になりやすい）。`songParams.json` の各曲に `residualVar` を追加、グローバル値は少観測曲のフォールバックとして残す。C は `a_i` デシル別の残差傾きを測定し、要否を #370 内で判断（モデル化自体は別issue）。#369 の後に着手。

## 3. 潜在能力 a_i の多次元化（#371）

### 課題

`a_i` がスカラー1個の rank-1 モデルは、乱打／縦連／ソフラン等で分かれる多次元スキル構造をすべて残差に落とす。「今後の課題」1.2 の The Onlyonez(−3.9) 等の曲固有残差、`R² ≈ 0.86` の頭打ちはこれで説明できる。beat-seeker の伸びしろランキング（譜面ペア相関）は多因子構造を暗黙に使っており、新BPIは1次元射影でその情報を捨てている。

### 検討する選択肢

| 案 | 概要 | 評価 |
|---|---|---|
| A: 残差 SVD 診断のみ | 残差行列を truncated SVD、第1〜2特異値の分散比を出す。第1因子ローディングを譜面属性と相関 | モデル変更なし、~1日。「rank-2/3 で何点稼げるか」の上限が分かる。**まずこれ** |
| B: rank-k ALS、BPI は z スカラー維持 | `t_ij = μ_j + Σ_f σ_jf·a_if + ε_ij`。`z_ij = (Σ_f σ_jf·a_if)/‖σ_j‖` で曲のローディング方向へ射影 | `z0/z100/gamma`/シフト法は無改修。多次元性は「より良い `z_ij` 予測」としてのみ効く（プレイ済み単曲BPIは実スコア由来で不変）。**A が正当化すれば** |
| C: 総合BPIを a_i ベクトルの関数に再定義 | 因子間の参照重みが必要 | ユーザー説明が難しい。**別の決定記録として先送り** |

### 方針

**A を #369 と並行で着手 → 正当化されたら B。** B の識別性は `Σ_i a_i a_iᵀ = I` ＋ 因子1を現行1次元 `a` に最も近い方向へアンカー（因子1＝総合地力、2..k＝補正軸）。`minSongsPerPlayer` を `k` に応じて引き上げ（k=2 で 20〜30、k=3 で 40+）、少曲プレイヤーは縮小推定で実質 k=1 に潰れる。C は扱わない。
