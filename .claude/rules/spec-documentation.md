# 仕様ドキュメントの運用

- `docs/proposals/` — 複数案を比較検討する仕様提案書を置く。対応issueがあれば冒頭にissue番号を明記する
- `docs/decisions/` — 決定記録（軽量ADR）。ファイル名は `NNNN-タイトル.md`（4桁連番）。ステータス（採用/不採用/一部採用）・背景・検討した選択肢の要約・結論と理由を書く
- 決定が下されたら、`docs/proposals/`の内容を`docs/decisions/`へ要約して記録し、提案書側は削除する（詳細を二重管理しない）
- 決定記録は書いた後に内容を変更しない。方針が覆った場合は新しい番号で記録を追加し、古い記録には「Nにより上書き」と追記する程度に留める
